# Product

## Register

product

## Users

Developers and reviewers working in local Git repositories, often while an AI coding harness is changing code. They need to understand a branch quickly, inspect the reason behind a hunk or existing line, and verify the evidence without leaving the review flow.

## Product Purpose

Lineage makes AI-assisted code changes reviewable. It combines local Git history with captured provider evidence so a reviewer can answer “why does this line exist?”, distinguish recorded provenance from Git inference, and export a durable decision record. Success means a repository opens once, stays available locally, and every review, exploration, capture, recovery, and export workflow remains usable on desktop, tablet, and phone.

## Brand Personality

Forensic, calm, exact. Lineage should feel like a trusted review instrument: dense when the evidence demands it, quiet when it does not, and candid about uncertainty or degraded capture.

## Anti-references

Not a generic SaaS dashboard, faux terminal, fake macOS window, card grid, cool-blue developer tool, or neon AI control room. Avoid decorative pills, glows, gradients, icon tiles, novelty motion, and interface chrome that competes with the diff.

## Design Principles

- Keep the diff as the primary artifact and place provenance at the point of review.
- Make recorded evidence, Git inference, queued capture, and errors visually unambiguous.
- Preserve the same capability on every viewport, changing sequence rather than removing tools.
- Prefer familiar review affordances and terse, specific language over decorative invention.
- Fail open for capture, but never hide degradation or imply evidence exists when it does not.

## Accessibility & Inclusion

Meet WCAG 2.2 AA, including keyboard-only operation, visible focus, reduced motion, non-color status cues, readable code and prose contrast, touch targets suitable for phones, and layouts that remain complete at 200% zoom.
